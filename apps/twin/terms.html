Twin 2.0 · 29 October 2026

What Twin does

Twin is a local personal journal and AI reflection tool. It can make mistakes, invent details or cite supplied memories inaccurately. It is not a person or a professional medical, legal or financial adviser. Verify outputs before relying on them. Patterns describe recorded data; the two-futures chart is an arithmetic scenario, not a prediction.

Requirements

Use a modern browser with HTTPS, Web Crypto, IndexedDB and free storage. Recording additionally needs a microphone, permission and MediaRecorder; transcription needs supported audio decoding and sufficient CPU memory. iPhone/iPad default to lightweight SmolLM2, primarily English-oriented. Full Qwen uses more memory; compatible Llama mode requires WebGPU and shader-f16. Performance is not guaranteed on every device. Test on your intended device.

Downloads and offline operation

Lightweight text-model weights are about 365 MB, full Qwen about 512 MB and Llama about 1 GB, plus semantic memory and runtime files. Optional transcription adds about 41 MB of weights plus support files. Download size is not RAM use. Initial downloads require Internet. Offline use depends on complete files and browser retention; the interface badge alone does not prove model readiness. There is no paid AI token balance, but model context and output lengths are limited.

Activation and data

A valid code activates this browser instance and is remembered for automatic opening. No new journal password is required. The same code protects new exported backups. Keep it private and separately from backups, and secure the device screen. Existing version 1 data still requires its original password for migration or restoration. A code alone does not recover a lost journal, and there is no cloud account or automatic sync. Restore replaces local data.

Voice limits

Saved recordings are limited to 3 minutes and 4 MiB each, with 20 MiB total encrypted recording storage. Recording drafts require Save this memory. Transcripts can be wrong: review before saving. Text AI does not interpret an untranscribed audio-only note. Record only content you have permission to record.
