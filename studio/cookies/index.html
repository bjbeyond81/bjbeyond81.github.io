4. Consent banner

Because the current Studio portal does not intentionally deploy non-essential analytics, behavioural advertising or profiling cookies, a consent banner is not currently displayed. If non-essential tracking technologies are introduced, the site will be updated to request consent before those technologies are activated and to provide an easy way to change or withdraw preferences.

5. Changes

This policy will be updated if the website starts using additional cookies, analytics, advertising tools or other tracking technologies.
